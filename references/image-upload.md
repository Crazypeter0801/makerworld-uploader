# 图片选择与故障处理

先看图片本身：主体完整、曝光清晰、背景不抢主体。横版 4:3 适合列表展示；竖版 3:4 要留足上下空间。真实使用场景说明用途，细节照说明接缝、纹理或装配关系。避免大段文字和过度滤镜。照片数量建议不是平台硬限制。

| 现象 | 下一步 |
|---|---|
| 文件无法解码、HEIC 或特殊格式 | 导出 JPEG/PNG 副本，保留原件；改后缀无效 |
| 手机照片方向错 | 导出时应用 EXIF 方向再看预览 |
| 已选图但没缩略图 | 查裁剪弹窗、页面错误、上传进度；不直接宣称成功 |
| 横版成功，竖版点不动 | 先处理上一张图的裁剪，不点击背后的页面 |
| 预览出现后消失 | 查网络和页面错误，预览可能只是本地 blob，并非已上传 |
| 保存后封面没有了 | 标记未完成，保留草稿地址；只修封面，不重新上传模型 |
| 图库已有照片 | 核对实际内容，跳过正确图片；不能用计数代替身份核对 |
| 页面控件无法定位 | discover 当前草稿页面，检查容器及按钮，不循环猜选择器 |

每次文件选中后不自动重传。确认失败原因并修正后至多重试一次；仍失败则报告具体卡点、草稿链接和本地截图，保留用户可接手的状态。诊断不要记录 cookie/token 或分享带认证信息的 HAR。
