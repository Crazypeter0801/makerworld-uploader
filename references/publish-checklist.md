# MakerWorld 发布检查清单

来源：官方 wiki `wiki.bambulab.com/zh/makerworld/tutorials/how-to-upload-models`（上游历史记录，本轮未重新核实）+ 历史表单约束，以当前页面为准。

## 一、上传类型（必选，选错会下架）

| 类型 | 适用 | 描述要求 |
|---|---|---|
| 原创 | 自己从零建的模 | 可直接发 |
| 二次创作 | 基于他人允许改编的模型改动 | **必须**写清改了什么；微小改动不算二次创作 |

## 二、文件通道（二选一，可都发）

| 通道 | 文件 | 说明 |
|---|---|---|
| 打印配置 | Bambu Studio 工程 `.3mf` | 含几何 + 切片参数 + 涂色 + 机型。用户可在 Bambu Handy 一键打印。平台会用**云切片**验证，文件里不强制带 gcode；本地先切一遍能提前发现规避区/超时问题 |
| 原始模型文件 | 3ds / amf / dwg / dxf / f3d / f3z / fcstd / iges / ipt / obj / ply / py / rsdoc / scad / shape / shapr / skp / sldasm / sldprt / slvs / step / stl / stp / studio3 / zip / 3mf / stpz | 给想自己改参数的人 |

**没有 .rar / .7z / .gcode。** `.zip` 是唯一压缩包格式。

## 三、必填字段

| 字段 | 约束 / 建议 |
|---|---|
| 模型名称 | 暂按 ≤ 50 字符准备，以当前表单 maxlength 为准。写「主体 + 尺寸 + 关键卖点」，例：`壁挂花盆支架 120×80 免支撑` |
| 封面 | **真实打印成品实拍**，至少 1 张。渲染图只能做补充图 |
| 分类 | 单选，选最贴近的（家居 / 工具 / 玩具 / 装饰…）。选太宽会减少推荐 |
| 许可证 | CC0 / BY / BY-SA / BY-NC / BY-NC-SA / BY-NC-ND 等。**授权他人商用与否是法律决定，必须让用户自己选**，agent 不要默认 |
| 可见性 | 公开 / 私密。默认公开，未打磨完的先存草稿 |
| 描述 | 脚本接受 Markdown 子集并转换为 HTML。建议结构：简介 → 打印参数 → 后处理 → 注意事项 |

## 四、打印配置附加要求

- 打印配置**至少 1 张实物照片**，否则可能被下架
- 配置名写在 `标题` 里，别堆关键词
- 给别人的模型加打印配置时，可勾「赠送积分」把 MakerReward 让给原作者

## 五、发布前自查

- [ ] `preflight.py` 的 `blockers` 为空，`warnings` 都已确认
- [ ] 料槽没有高低温混打、没有自定义预设（`preflight.py` 的 blockers 为空）
- [ ] 本地切过一遍，知道大概的打印时长与耗材（云切片有 5 分钟/盘上限，但那是切片耗时不是打印耗时）
- [ ] 封面是实拍，预览图和当前层高/参数一致
- [ ] 标题没超长、没堆砌关键词
- [ ] 许可证是用户亲自选的
- [ ] 二次创作已在描述里说明来源与改动
- [ ] **发布动作由人确认**（agent 只到草稿）

## 六、常见报错

| 现象 | 原因 | 处理 |
|---|---|---|
| 「高低温耗材无法混合打印」 | 料槽里同时有低温（PLA/PETG）与高温（ABS/PC/PA/PETG-CF） | 清成同一温度区间，只留实际用到的槽位 |
| 「配置文件中有自定义耗材/打印机预设」 | 用了自己调过的预设 | 换回 Bambu 官方预设 |
| 切片校验失败（文件格式/损坏） | 导出成了通用 3mf 或文件损坏 | 用 Bambu Studio 打开后 Ctrl+S 重存再传 |
| 上传后显示 0KB | 3mf 太大，解压解析失败 | 同上，Ctrl+S 重存 |
| 「超出规避区」 | 模型/支撑擦料塔贴边，或机型规避区不同 | 往中间挪；擦料塔与耗材清理量恢复默认；或换 H 系列 |
| 云切片超时 | 每盘 5 分钟 / 3mf 15 分钟上限 | 拆盘，或改用「文件」形式上传 |
| 页面 403「请稍候…」 | Cloudflare 挑战 | 关掉 headless；用真实 Chrome 重开；必要时人工过一遍挑战 |
| 上传按钮点了没反应 | UI 改版，选择器失效 | 跑 `mw.py discover` 拿新结构 |
